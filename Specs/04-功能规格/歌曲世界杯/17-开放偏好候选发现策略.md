# 开放偏好候选发现策略

> 状态：待实现  
> 优先级：P0  
> 依赖：`16-在线优先候选发现与意图澄清.md`

## 1. 目标

当用户没有明确指定歌手，例如“想要适合雨夜独处、克制但不阴郁的中文歌”，候选池 Agent 仍应可靠地产生可开赛的歌曲池。在线搜索负责发现，MusicBrainz 负责核验，Milvus 只为已核验候选补充主题解释；本地目录不能决定探索边界。

## 2. ReAct 决策原则

不是预设的搜索步骤。Supervisor 每轮读取黑板：已提取偏好、已用检索角度、网页证据密度、核验成功率、候选缺口、失败原因和剩余预算，自主选择下一项工具调用。

可选行动包括：

- 拆解或重估偏好信号；
- 以场景、情绪、流派、语言、年代、文化语境或相邻艺人形成检索假设；
- 搜索公开资料、抽取歌曲证据、核验 MusicBrainz；
- 对低收益方向转向，或在证据不足时结束并说明缺口；
- 对已核验候选检索 Milvus 主题卡，以增强排序理由，不可用其发现新实体。

运行时只能限制重复无收益、工具/时间预算、实体歧义和数据契约，不能规定正常的工具顺序或要求每类搜索都执行一次。

## 3. 偏好信号模型

`PreferenceHypothesis` 记录带来源的可检验信号：

| 信号 | 示例 | 可转化检索切面 |
| --- | --- | --- |
| 场景 | 雨夜独处、通勤 | 场景歌单、编辑推荐、播放列表 |
| 情绪与能量 | 克制、温柔、不阴郁 | 情绪标签、乐评、相近作品 |
| 流派/声音 | dream pop、R&B、女声 | 流派代表作、风格歌单、相邻艺人 |
| 语言/地区/年代 | 华语、90 年代 | 地区与年代专题、音乐媒体 |
| 文化语境 | 城市漂泊、青春回望 | 主题专题、创作背景、歌词主题 |

模型可提出假设，但不得把假设当事实；网页中的“歌名 + 艺人名”证据和 MusicBrainz 对齐仍是入池门槛。

## 4. 查询策略

- 每轮由 Agent 生成互补而非同义重复的查询；它可只选最有信息量的 1–5 条。
- 首轮优先覆盖用户最强、最明确的信号；之后依据“每条查询带来的可核验曲目数”改变方向。
- 若某一切面低收益，Agent 可转向更具体的子流派、年代/地区、编辑歌单或相邻艺人；不得机械地把所有维度轮一遍。
- 若输入过泛，Agent 可优先请求最小化澄清（如语言或能量偏好）；只有该不确定性确实阻止可靠发现时才阻塞。

## 5. 质量与可观测性

每一轮保存：`hypothesis`、查询、查询目的、网页来源数、证据线索数、MusicBrainz 成功/拒绝数、去重后新增数和转向原因。最终返回的 trace 不暴露思维链，只暴露上述可审计事实。

验收输入至少覆盖：

1. 场景型：`雨夜独处、克制但不阴郁的中文歌`；
2. 声音型：`想听带一点灵魂乐、适合傍晚散步的女声`；
3. 文化语境型：`关于城市漂泊和长大后的失落感`；
4. 混合型：`90 年代到 00 年代的华语 R&B，温柔一点`。

对于这些输入，验收重点不是固定来源比例，而是：候选与输入有关、可追溯、经 MusicBrainz 核验、无关本地种子不混入，并且失败时明确说明在线证据或核验的真实缺口。
