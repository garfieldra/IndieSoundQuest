# 音乐偏好事件与长期记忆

- 状态：已实现首版事实采集

## 原则

本期世界杯逐场选择是报告与探索方向的主要事实，长期档案只作跨场补充。证据强度为：用户明确表达 > 世界杯逐场选择 > 推荐反馈 > Agent 推测；推测不得直接固化。

## 选择事件

每个完成对局派生 `TOURNAMENT_VOTE`，包含赛事、对局、轮次、胜出歌曲/艺人和落败歌曲/艺人。档案保存近期事件，用于识别反复选择；冠军只是其中一个事实。

## 长期固化

可固化用户明确喜欢的艺人、用户确认的总结，以及跨多场反复出现的稳定倾向。单场偶然选择、人格彩蛋、教育背景或心理状态推测不得作为稳定档案。访客可关闭档案参与候选生成或重置档案。

## 验收

- 完成赛事后档案包含逐轮胜败，不只有冠军。
- 报告 Agent 继续读取完整赛事事实。
- 档案升级后既有 API 仍可读。
