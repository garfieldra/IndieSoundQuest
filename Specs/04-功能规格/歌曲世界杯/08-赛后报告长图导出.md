# 赛后报告长图导出

**前置规格：** `05-赛后偏好报告与长图.md`、`06-Java报告任务编排与前端接入.md`、`07-报告Agent子Agent与证据链.md`

## 1. 目标与边界

把已生成的单场偏好报告导出为一张可保存的 PNG 长图。导出完全在浏览器本地完成，不新增 Java/Python 接口、不上传报告或访客数据，也不做社交分享。

本期只导出报告，不导出完整赛事对阵图。

## 2. 交互

- 仅在报告状态为 `READY` 时显示“下载报告长图”。
- 点击后按钮进入“正在生成长图…”，防止重复触发；生成成功后先打开长图预览，再由用户点击下载。
- 下载文件名为 `indie-sound-quest-report-{reportVersion}.png`；失败时给出可理解提示，报告页面继续可读。
- 页面仍保留可点击的音乐平台与来源链接；导出的图片以文字显示链接来源，不包含可点击区域。

## 3. 技术方案

- 前端使用 `html-to-image` 的 `toPng`，不使用第三方截图服务。
- 渲染一个仅用于导出的 `.report-export` DOM 容器，固定宽度 `1080px`，不复用屏幕尺寸下的响应式布局。
- 导出前等待字体与图片加载；每张无法读取或跨域失败的图片替换为本地 CSS 唱片标签，不让单张封面阻断导出。
- PNG 使用 `pixelRatio: 2`；背景固定暖白色，避免透明底。
- 导出 DOM 默认不占据正常布局，通过屏幕外定位；导出期间可见给无障碍技术的进度文本。

## 4. 内容与展示规则

导出顺序：本场冠军（封面、歌名、艺人、赛事规模）、报告版本、摘要、偏好维度、歌曲推荐、艺人推荐、人格彩蛋、免责声明、小号 `IndieSoundQuest` 页脚署名。

| 推荐来源 | 页面与长图标识 | 长图附加信息 |
| --- | --- | --- |
| `catalog_verified` | 已验证音乐目录 | 歌曲/艺人名称与推荐理由 |
| `web_discovered` | 网络发现 · 待核验 | 来源标题与“请以音乐平台搜索结果为准”；不展示冗长原始网址 |

不得导出访客 ID、Cookie、模型 Prompt、工具调用记录、原始网页摘要或任何内部 UUID。

## 5. 视觉基调

- 与网站保持同一套“暖白唱片内页”语言：暖白底、低饱和棕灰正文、砖红色只用于关键动作或状态。
- 标题使用现有宋体回退栈，正文保持清晰的无衬线阅读体验；以留白、细分隔线和低对比层级组织信息。
- 不使用大面积渐变、玻璃拟态、Emoji、夸张阴影、无意义纹理或社交平台式分享组件。
- 冠军封面为首屏视觉锚点；无可用封面时使用简洁唱片标签占位，不以破图替代。

## 6. 验收标准

- [ ] `READY` 报告可下载 1080px 宽 PNG；
- [ ] 不同屏幕宽度下导出视觉一致；
- [ ] 包含网络发现项时，长图明确保留待核验与来源文字；
- [ ] 无封面或外部封面跨域失败时仍能下载；
- [ ] 不产生任何新的后端请求或用户数据外传；
- [ ] 连续点击不会并行触发多个导出任务。
- [ ] 先展示预览，用户确认后才下载 PNG；视觉风格与报告页面一致。
