# 歌曲试听与平台跳转

> 状态：已实现并验证  
> 版本：v1.0  
> 范围：候选确认页、世界杯对局页、Java 音乐资源接口

## 1. 目标

用户在确认候选歌曲和进行一对一选择时，可以点击歌曲卡片试听短片段；没有可用试听时，仍能明确跳转到音乐平台搜索歌曲。试听行为只用于当次播放控制，不进入长期偏好档案，也不作为报告 Agent 的证据。

## 2. 已确认的产品决策

1. 必须提供外部平台跳转。
2. 面向中国大陆用户，普通搜索入口优先展示网易云音乐；首版只生成公开搜索链接，不调用其非公开接口。
3. 点击歌曲卡片主体用于试听；对局投票改为独立的“留下这首”按钮，避免试听与投票混淆。
4. 无试听时显式展示“暂无试听”和“去网易云搜索”。
5. 不记录试听次数、试听时长或播放完成度，不把试听行为传给任何 Agent。

## 3. 数据来源与合规边界

### 3.1 Apple iTunes Search API

- 请求：`GET https://itunes.apple.com/search`
- 参数：`term={艺人+歌名}`、`country=CN`、`media=music`、`entity=song`、`limit=10`
- 使用字段：`trackId`、`trackName`、`artistName`、`collectionName`、`previewUrl`、`trackViewUrl`
- 试听音频只能由浏览器直接流式播放；Java 服务不得下载、代理、转码或缓存音频文件。
- 有试听时必须就近展示“由 Apple 提供的 30 秒试听”和 Apple Music 条目链接。
- Apple 查询按需发生，不在候选池生成时批量调用；命中结果缓存 7 天，未命中结果缓存 24 小时，以控制外部请求量。

### 3.2 网易云音乐

- 首版仅生成网页搜索链接：`https://music.163.com/#/search/m/?s={艺人+歌名}&type=1`。
- 不抓取页面、不解析搜索结果、不调用逆向或非公开 API，也不声称链接对应某个已核验的网易云曲目 ID。
- 因此按钮文案必须是“去网易云搜索”，不能写成“在网易云播放”。

## 4. 同曲匹配规则

Apple 返回的结果只有在以下条件全部满足时才可以用于站内试听：

1. 歌名经过 Unicode NFKC、繁简统一、大小写和标点归一化后完全一致；
2. 主艺人归一化后完全一致；内部艺人名包含历史名称时（例如“张悬／安溥”），允许任一明确别名完全匹配；
3. 有专辑信息时将专辑一致作为加分项；
4. 多个候选无法形成唯一高置信结果时，返回无试听，不猜测版本；
5. `previewUrl` 与 `trackViewUrl` 必须是 HTTPS 公网地址。

MusicBrainz 仍是歌曲身份底座；Apple 只附着试听和商店资源，不反向改变内部 Recording 身份。

## 5. 后端设计

### 5.1 持久化模型

新增 `recording_listening_asset`：

| 字段 | 含义 |
|---|---|
| `recording_id` | 内部 Recording UUID |
| `provider` | 首版固定为 `APPLE_ITUNES` |
| `storefront` | 首版为 `CN` |
| `status` | `AVAILABLE` / `UNAVAILABLE` |
| `provider_item_id` | Apple trackId，可空 |
| `preview_url` | 短试听 URL，可空 |
| `provider_track_url` | Apple Music 条目 URL，可空 |
| `matched_*` | 实际匹配到的歌名、艺人、专辑，供审计 |
| `checked_at` / `expires_at` | 查询与缓存有效期 |

数据库只保存 URL 和匹配审计信息，不保存音频内容。

### 5.2 REST API

`GET /api/v1/recordings/{recordingId}/listening-options`

成功响应示例：

```json
{
  "recordingId": "uuid",
  "status": "AVAILABLE",
  "preview": {
    "provider": "APPLE_ITUNES",
    "url": "https://audio-ssl.itunes.apple.com/...",
    "providerTrackUrl": "https://music.apple.com/cn/...",
    "attribution": "30 秒试听由 Apple 提供"
  },
  "platformLinks": [
    {
      "provider": "NETEASE_CLOUD_MUSIC",
      "label": "去网易云搜索",
      "url": "https://music.163.com/#/search/m/?s=...&type=1"
    }
  ]
}
```

外部服务超时、无结果或匹配不确定时仍返回 HTTP 200，`status=UNAVAILABLE`，并保留网易云搜索链接。只有 Recording 不存在时返回 404。

## 6. 前端交互

### 6.1 候选确认页

- 候选卡片主体可点击试听；卡片底部保留独立“移除”按钮。
- 第一次点击时显示轻量加载状态；成功后播放，再次点击暂停。
- 无试听时在卡片内显示“暂无试听”，同时保留“去网易云搜索”。

### 6.2 对局页

- 点击任一歌曲卡片主体只控制试听，不会提交选择。
- 每张卡片具有独立的“留下这首”按钮，只有该按钮会调用投票接口。
- 同一时间最多播放一首；切换歌曲时先暂停上一首。
- 投票成功、切换对局或离开页面时停止当前试听。

### 6.3 视觉与可访问性

- 延续暖白唱片内页风格，不使用 emoji。
- 播放、暂停、加载和无试听均使用文字状态，不依赖动画表达唯一含义。
- 所有交互均可通过键盘聚焦和触发；外部链接在新标签页打开。

## 7. 非目标

- 不接入网易云、QQ 音乐或酷狗的非公开接口；
- 不实现完整歌曲播放、播放器队列、歌词同步或音频下载；
- 不记录试听行为，不建立新的偏好信号；
- 不让候选池 Agent 或报告 Agent 决定试听资源；
- 不在首版支持多个试听 Provider 自动切换。

## 8. 验收标准

- [x] 已核验 Apple 匹配的歌曲可以在候选页和对局页直接试听；
- [x] 试听旁展示 Apple 归属和条目跳转；
- [x] 无试听或 Apple 不可用时赛事不受阻，并显示网易云搜索入口；
- [x] 点击歌曲卡不会投票，只有“留下这首”会投票；
- [x] 切换播放对象、投票和卸载页面时不会残留多个音频；
- [x] Java 对重复请求使用缓存，不会每次点击都访问 Apple；
- [x] 低置信或歧义匹配不会返回试听 URL；
- [x] 数据库、日志与 Agent 输入中不存在音频内容或试听行为记录。

## 9. 实现验证记录

- Java 单元测试覆盖别名精确匹配、歧义拒绝、非 Apple URL 拒绝、缓存命中与无试听降级；
- 前端测试覆盖试听状态文案，生产构建通过；
- 《南国的孩子》真实命中 Apple CN：返回 Apple 30 秒试听与 Apple Music 条目链接；
- 相同请求首次解析约 3.8 秒，缓存请求约 0.08 秒；
- Apple 音频响应支持 Range，且前端直接访问，不经过 Java 代理；
- 《潮氣吹過後山破廟時 Misty Mountain Pagoda》真实返回 `UNAVAILABLE`，同时保留网易云搜索链接；
- Flyway V12 已在 Docker MySQL 中成功应用，Java 与 Web 容器健康运行。
