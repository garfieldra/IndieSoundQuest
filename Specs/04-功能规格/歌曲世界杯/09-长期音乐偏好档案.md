# 长期音乐偏好档案

**前置规格：** `02-Agent候选池策展.md`、`05-赛后偏好报告与长图.md`、`07-报告Agent子Agent与证据链.md`

## 1. 目标与首版边界

在既有的访客会话内，持续聚合多场已完成歌曲世界杯的可解释信号，形成可供用户阅读、也可供 Agent 识别变化的长期音乐偏好档案。

**产品优先级：** 每一场歌曲世界杯都是一次独立、可解释的音乐探索实验。下一步探索必须首先依据刚完成赛事的冠军、晋级路径、淘汰关系与候选分布；用户本次探索意图次之；长期档案仅是可关闭的弱背景，不得单独决定候选或推荐。

首版不做账号、登录、跨设备同步或复杂鉴权；档案仅由现有 `GuestSession` 归属控制。用户可一键重置自己的档案。赛事、报告与档案均不公开。

## 2. 更新与数据来源

- 每场赛事完成时立即写入结构化事实：候选、全部投票、晋级路径、冠军与可验证的偏好信号。
- 单场报告完成后，补充其已经通过校验的维度摘要；报告失败不阻塞结构化档案更新。
- 第 1 场即可生成档案，但仅称为“初步观察”；跨场重复支持后才提升为稳定趋势。
- 最小验收样本为 3 场完成赛事。

## 3. 数据模型

```text
GuestSession 1 --- 1 MusicPreferenceProfile
MusicPreferenceProfile 1 --- n ProfileObservation
MusicPreferenceProfile 1 --- n ProfileSourceTournament
```

`MusicPreferenceProfile` 保存版本、最近更新时间、已纳入赛事数、结构化 JSON 摘要与文字总结状态。

`ProfileObservation` 保存：维度名、方向（偏好/当前较少选择）、支持赛事数、支持证据数、置信度、状态（初步/稳定）、解释与最近证据引用。

不得保存模型 Prompt、网页原文、Cookie 明文或任何现实身份推断。

## 4. 聚合规则

- 使用固定核心维度（叙事性、声线气质、节奏/编曲、情绪浓度、风格跨度、艺人/年代分布）作为稳定坐标；Agent 可补充最多 2 个自定义维度。
- 聚合服务先以确定性规则统计跨场支持次数、覆盖赛事数与置信度；LLM 只负责基于这些受约束输入生成可读总结。
- 单场出现的结论只能标记为“初步观察”；至少在 2 场出现并具有足够事实支持，才可标记为“稳定趋势”。
- “当前较少选择”仅在多场重复时展示，采用中性措辞；不得将其描述为价值判断或绝对不喜欢。
- 不生成长期人格彩蛋，也不推断心理、教育、职业、收入或现实身份。

## 5. Agent 使用边界

- 单场报告 Agent 以本场赛事事实为唯一主输入；如读取长期档案，必须仅用于区分“本场选择”与“长期趋势”，不得用它覆盖本场结论。
- 下一步探索/候选池 Agent 的输入优先级固定为：`本场赛事事实 > 用户本次探索意图 > 长期偏好档案`。
- 候选池生成 Agent 默认可参考长期档案，用户可关闭“参考我的长期偏好”；关闭后不读取该上下文。
- 长期档案可帮助 Agent 识别本场与既有偏好的差异，并据此提出有理由的跨风格探索，但不能把用户锁定在既有艺人或风格中。
- 本地目录优先；目录不足时由 Agent 自主决定是否使用 Tavily 网络研究。网络发现候选继续标记为 `web_discovered` / “网络发现 · 待核验”。
- Agent 或 LLM 失败时，结构化聚合照常保存；页面显示“文字总结暂不可用”，并允许重试。

## 6. 用户体验

新增“我的听歌轨迹”入口，展示：

- 初步观察/稳定趋势及对应置信度；
- 最近三场的变化与代表性冠军；
- 代表歌曲、艺人及可追溯赛事证据；
- 最近更新时间与已纳入赛事数；
- “参考我的长期偏好”开关；
- “重置我的档案”操作与二次确认。

## 7. 留存与隐私

- 档案与源赛事按 `GuestSession` 隔离，不做对外可见标识。
- 一键重置仅删除当前访客会话的档案及观察记录，不影响其他访客。
- 设计目标为 180 天无活动自动清理；首版可先实现为可执行的定时清理任务，不依赖登录体系。

## 8. API 草案

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| `GET` | `/api/v1/music-preference-profile` | 获取当前访客档案 |
| `POST` | `/api/v1/music-preference-profile/refresh` | 重试文字总结或手动刷新 |
| `DELETE` | `/api/v1/music-preference-profile` | 重置当前访客档案 |
| `PATCH` | `/api/v1/music-preference-profile/settings` | 更新“参考长期偏好”开关 |

## 9. 验收标准

- [ ] 1 场赛事后出现清晰标注的初步观察；
- [ ] 3 场赛事后产生带跨场证据的稳定趋势；
- [ ] 关闭开关后候选池 Agent 不接收长期档案；
- [ ] 单场报告能区分本场与长期趋势；
- [ ] LLM 总结失败时，结构化档案仍可读取；
- [ ] 重置仅影响当前访客会话；
- [ ] 不存在账号或登录前提，不生成敏感身份结论。
