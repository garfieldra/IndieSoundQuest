# Agent 轨迹观测与质量评估体系

- 状态：开发中

## Trace

记录 runId、业务类型、Action 序列、reasonCode、工具调用与耗时、网络来源数、MusicBrainz 核验数、候选/拒绝数、重试、终止原因、首事件延迟和总耗时。不得记录 API Key、内部地址、完整 Prompt、思维链或敏感信息。

## 黄金用例

1. 徐佳莹、艾怡良、郑宜农，32 首赛事与 32 首补位。
2. Asen、Kanye West、周杰伦、陶喆，必要时阻塞歧义。
3. 只玩张悬/安溥，不跨艺人。
4. 雨夜、克制、疏离的中文歌，无明确艺人。
5. 本地目录无相关作品，网络发现仍可开赛。
6. 搜索或 MusicBrainz 部分失败。
7. 同名、版本重复和艺人歧义。
8. 报告引用逐轮胜负事实。

## 指标与闸门

评估候选/补位完成率、目录存在率、MusicBrainz 核验率、重复率、约束违反率、歧义阻塞率、证据覆盖率、报告事实一致性、耗时与终止原因。主池不足、目录不存在、锁定艺人越界、未解析实体泄漏或重复版本均为阻塞问题。
